七步

数据体检

检查项目元数据 / 索引 / 原文 / 草案 / 练习记录是否自洽；修复只做「能从现有数据重算」的事，删除类的一律只报告。

简历要点（只写真实做过的事）

含技能清单、亮点（每条带依据）、项目经历、待补方向；可导出 Markdown（CLI：flow resume --out=resume.md）

搜集招聘信息

招聘站点（BOSS / 拉勾）对抓取有反爬：抓得到就抓（搜索面板），抓不到就把 JD 正文粘进来——识别、入库、算匹配度走的是同一套。

岗位推荐

匹配度 = 覆盖 55% + 硬要求 30% + 方向广度 15%；同级岗位里新发布的排前面
地点/薪资是硬门槛；没写薪资的岗位不会被筛掉
