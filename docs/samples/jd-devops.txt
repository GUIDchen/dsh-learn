示例科技（示例数据，可删） 招聘 高级 DevOps / SRE 工程师

岗位职责
1. 负责 Kubernetes 集群的稳定运行、滚动发布、容量规划与故障演练
2. 负责 Prometheus / Grafana 监控体系与告警规则，参与 on-call 值班
3. 负责 CI/CD 流水线（GitLab CI + ArgoCD）与镜像仓库治理
4. 参与线上问题排查与事后复盘，沉淀可复用的运维手册

任职要求
1. 熟悉 Linux 与 Shell，5 年以上运维或 SRE 经验
2. 熟悉 Docker 与 Kubernetes 滚动发布、探针与资源限制
3. 熟悉 Prometheus 指标查询与告警规则配置
4. 掌握 Python 或 Go 中至少一种，能写自动化脚本
5. 有较强的排障能力，能看日志、抓包、定位性能瓶颈

加分项
1. 了解 Terraform 与基础设施即代码
2. 有大规模集群（500+ 节点）经验优先
3. 了解 eBPF / 可观测性生态

工作地点：深圳　薪资：35-60K·15薪　3 天前发布
